# ADR 템플릿

**택한 것과 버린 것.** 되돌리기 비싼 선택을 할 때만 쓴다.

`status`: `draft`(제안) → `done`(결정) → `dropped`(철회 또는 대체됨)
대체된 경우 새 ADR 의 `links` 에 이 ID 를 적는다.

```markdown
---
id: ADR-0001
title: <결정을 한 문장. "X 를 쓴다" 형태>
status: draft
links: [ARCH-0001]
updated: <YYYY-MM-DD>
---

## 맥락
<무엇을 정해야 하고, 왜 지금 정해야 하는가>

## 결정
<택한 것. 한두 문단>

## 버린 선택지
| 선택지 | 왜 버렸나 |
|---|---|

## 결과
- 좋아지는 것: <>
- 나빠지는 것: <비용을 적는다. 없다고 쓰면 거짓이다>

## 되돌리는 비용
<나중에 뒤집으려면 무엇을 해야 하나>
```

## 규칙
- **버린 선택지가 없는 ADR 은 ADR 이 아니다.** 비교가 없으면 그냥 설명이고, ARCH 에 쓴다
- "나빠지는 것" 을 비우지 않는다. 비용 없는 결정은 결정이 아니라 발견이다
- `done` 이 된 ADR 은 고치지 않는다. 생각이 바뀌면 새 ADR 로 대체한다
- 되돌리는 비용이 싸면 ADR 을 쓸 필요가 없다 — 그냥 하고 나중에 바꾼다
