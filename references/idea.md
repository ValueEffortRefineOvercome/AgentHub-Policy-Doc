# IDEA 템플릿

아직 **할지 모르는** 생각. 설계하지 않고 결정하지 않는다 — 그건 ARCH·ADR 이다.

`status`: `draft`(탐색 중) → `open`(채택, REQ 로 이어짐) → `dropped`(버림)

```markdown
---
id: IDEA-0001
title: <한 문장. 명사구가 아니라 하고 싶은 것>
status: draft
links: []
updated: <YYYY-MM-DD>
---

## 문제
<지금 무엇이 불편한가. 해결책을 쓰지 않는다>

## 가설
<이렇게 하면 나아질 것이다. 한두 문단>

## 왜 지금
<미뤄도 되는 이유가 없다면 그게 뭔가. 없으면 "급하지 않음" 이라고 적는다>

## 비용 짐작
<자릿수만. "하루" / "한 주" / "모름">

## 버릴 조건
<무엇이 사실이면 이 아이디어를 접는가>
```

## 규칙
- **버릴 조건이 없으면 IDEA 가 아니다.** 접을 수 없는 생각은 이미 결정이다
- 비용을 모르면 "모름" 이라고 적는다. 추측한 숫자가 나중에 근거로 쓰인다
- 채택되면 REQ 를 새로 만들고 IDEA 는 `open` 으로 남긴다. IDEA 를 REQ 로 고쳐 쓰지 않는다
